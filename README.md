# Czytelnia

Dodatek do NVDA autorstwa Karola Olejnika do słuchania audiobooków zapisanych na komputerze.

Pozwala dodawać książki z folderów oraz archiwów ZIP, RAR i 7z. Zapamiętuje miejsce słuchania, głośność i prędkość. Obsługuje zakładki oraz wyłącznik czasowy.

## Pobieranie i uruchomienie

Gotową paczkę `.nvda-addon` znajdziesz w [najnowszym wydaniu](https://github.com/karolasty83/czytelnia/releases/latest). Pobierz ją, zainstaluj w NVDA i ponownie uruchom czytnik.

Bibliotekę otwiera skrót **NVDA+Shift+C**. Podręcznik jest dostępny pod **F1** w oknie Czytelni.

Wymagane NVDA 2025.1 lub nowsze.
